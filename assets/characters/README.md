# 角色图片替换说明

## 如何替换猫小九角色形象

将角色图片放入本目录，文件名对应境界名称：

| 文件名 | 对应境界 | 建议尺寸 |
|---|---|---|
| 武者.png | 武者（1-9星） | 512x512像素 |
| 武师.png | 武师（1-9星） | 512x512像素 |
| 武灵.png | 武灵（1-9星） | 512x512像素 |
| 武王.png | 武王（1-9星） | 512x512像素 |
| 武皇.png | 武皇（1-9星） | 512x512像素 |
| 武宗.png | 武宗（1-9星） | 512x512像素 |
| 武尊.png | 武尊（1-9星） | 512x512像素 |
| 武圣.png | 武圣（1-9星） | 512x512像素 |
| 虚帝.png | 虚帝（1-9星） | 512x512像素 |
| 武帝.png | 武帝（1-9星） | 512x512像素 |
| 神帝.png | 神帝（1-9星） | 512x512像素 |

## 图片要求
- 格式：PNG（支持透明背景）
- 尺寸：建议512x512像素，正方形
- 风格：卡通冒险风格，猫小九角色形象
- 来源：可从漫画截图中裁剪角色形象

## 注意事项
- 如果某个境界没有对应图片，应用会自动显示默认的🐱emoji
- 替换图片后，在应用中点击"家长入口 → 系统设置 → 刷新角色图片"即可生效
- 图片文件名为中文，需确保编码正确
